# Contributing

This page is for people changing the API. If you are running it, start
with the [README](../README.md). Endpoint detail lives in
[analytics.md](analytics.md) and [question-answering.md](question-answering.md).

## How a change happens

One issue, one branch, one pull request. Roxana reviews and merges.
Automated tests run on every change.

Issue titles start with one emoji code, such as 🛠️ or 📄. Pull request
titles are a plain sentence. The steps, the test commands, and the
templates are in [AGENTS.md](../AGENTS.md).
